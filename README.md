# Countdown Timer

A simple countdown timer that have built with HTML, CSS and JavaScript then scaffolded with Vite.

## Features

- Set a countdown time
- Live display of remaining time
- Runs in the browser with no backend

## Technologies Used

- HTML5
- CSS
- JavaScript (Vanilla)
- Vite for scafolding the projects files 

## Requirements

- Node.js 18 or higher
- npm

## Getting Started

1. Clone or download this project.
2. Open the project folder in a terminal.
3. Install dependencies:
4. Then run it via terminal or live server
